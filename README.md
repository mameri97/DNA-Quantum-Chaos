# Quantum Chaos and Random Matrix Theory in DNA Base Pairs

**Computational study of electronic energy spectra and spectral statistics in Watson–Crick AT and GC base pairs.**

## Overview

This repository contains the computational codes, molecular geometries, datasets, and statistical analysis associated with a research project investigating quantum-chaotic behavior in DNA nucleobase pairs.

The primary objective is to investigate the spectral properties of Watson–Crick adenine–thymine (AT) and guanine–cytosine (GC) base pairs using concepts from quantum chaos and random matrix theory (RMT).

The study focuses on the statistical properties of electronic energy spectra, including nearest-neighbor level-spacing distributions, adjacent-gap ratios, spectral correlations, and number variance. The results are compared with standard statistical ensembles, including Poisson, Gaussian Orthogonal Ensemble (GOE), and semi-Poisson, as well as other relevant statistical distributions.

## Scientific Motivation

Random matrix theory provides a powerful framework for investigating spectral correlations and quantum-chaotic behavior in complex quantum systems.

DNA base pairs provide an interesting molecular system in which electronic structure and intermolecular interactions can be investigated through spectral statistics. This project explores whether the electronic spectra of AT and GC base pairs exhibit statistical signatures associated with different random matrix ensembles.

The broader motivation is to investigate possible connections between electronic spectral correlations, molecular interactions, and the physical properties of DNA.

## Computational Methodology

### 1. Molecular Geometries

Watson–Crick AT and GC base-pair geometries are considered. Molecular configurations are generated by introducing controlled geometrical variations while maintaining the relevant hydrogen-bonding conditions.

### 2. Quantum-Chemical Calculations

Electronic-structure calculations are performed using Python and PySCF.

The computational framework includes:

- Density Functional Theory (DFT).
- B3LYP exchange-correlation functional.
- def2-SVP basis set.
- Ground-state electronic-structure calculations.

### 3. Spectral Analysis

The eigenvalues of the symmetrically orthogonalized Fock matrix are used to investigate the electronic spectral properties.

The analysis includes:

- Energy-level spacings.
- Normalized nearest-neighbor spacing distributions.
- Adjacent-gap ratios.
- Spectral unfolding.
- Number variance.
- Spectral compressibility.
- Comparison with Poisson, GOE, and other statistical distributions.

### 4. Statistical Analysis

Python and Wolfram Mathematica are used for computational data processing, statistical calculations, visualization, and comparison with theoretical random matrix predictions.
